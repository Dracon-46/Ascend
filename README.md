### Instalar no Android

1. Baixe o `Ascend.apk` no celular.
2. Abra o arquivo. Se o Android pedir, permita instalar apps desta fonte.
3. As próximas versões atualizam por cima, sem perder nada: seus dados ficam no servidor.
